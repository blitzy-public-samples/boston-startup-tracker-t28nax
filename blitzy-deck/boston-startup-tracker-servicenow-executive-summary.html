Executive Summary

Boston Startup Tracker, rebuilt on ServiceNow

A venture-data product that could not be built or started is now one specified application: a validated package, plus the guides that build the rest.

For non-technical leadership · Scoped application x_bst_startuptrk · Version 1.0.0

What was delivered

  • 10 Tables, seven core entities
  • 49 Access rules, previously none
  • 31 Interface operations, six resources
  • 36 Tests designed, in ten suites

One importable package of 314 configuration records, plus six sequenced guides for the parts the platform builds itself.

How data arrives and leaves

flowchart LR
  accTitle: How data reaches the tables and how it leaves them
  accDescr: Crunchbase and LinkedIn both reach two named connections bound by name, which feed two scheduled flows running on a cadence between six and forty-eight hours. A fallback dataset of six files and sixty-five rows can feed the same flows instead. The flows apply four cleaning rules that trim, de-duplicate, normalise and reject, and write to ten tables. Everything read back out passes through forty-nine access-control rules, which serve both the interface layer of thirty-one operations and the five-page Service Portal.

How it will be proven

  • 9 Pre-ship checks
  • 36 Tests designed, in ten suites
  • 100% Tables and resources covered
  • 11 Required gates, checked after install 
flowchart LR
  accTitle: The nine checks between a package and an accepted installation
  accDescr: Nine validation checks run first, then the package is imported and previewed within a six-hundred-second budget. If the preview reports any problem the package is fixed and re-issued; if it reports none the package is committed. Eleven required gates then run: if all pass the installation is accepted, and if any fails it is rolled back.

timeline
  accTitle: The migration timeline, in three phases
  accDescr: Three phases in relative order. Install: validate the package, then import, preview and commit it, then clear the twelve acceptance-blocking checks.
