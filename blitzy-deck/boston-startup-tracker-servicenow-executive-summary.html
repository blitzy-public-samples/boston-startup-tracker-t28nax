Part One

Why it matters

Risks and how they are held

Level Reviewer What could go wrong How it is held
High Security Paid-tier enforcement fails silently, and an administrator checking it sees everything and proves nothing Twenty-one checks, each run as a user holding one role and no elevated access
High DevOps Recovery deletes the application and all its data — the one irreversible step in the delivery Fires only on a failed install or a failed gate; the install preview must be clean first
High API/Integration A leaked partner key cannot be contained by changing anything inside this application No credential ships anywhere; both connections named, and tested before either flow is saved
Medium Data/SME A stored portfolio count drifts when records arrive by a route that skips the rules Recalculation after every bulk load, and company deletion exercised end to end
Medium UX Five tabs replace six, and links now carry parameters rather than paths A five-screen walkthrough performed as a free user, not as an administrator

Paid subscription billing has no platform equivalent. It is formally flagged, not half-built. Eleven further items are recorded alongside it.
